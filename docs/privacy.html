Privacy Policy

Last updated: November 4, 2026

This policy applies to "Protein Plate Publisher", an application operated by Protein Plate (proteinplatehq.gumroad.com) that publishes Protein Plate's own video content to its own YouTube channel.

What the app does

The app uploads videos (YouTube Shorts) with titles and descriptions to the Protein Plate YouTube channel on a schedule. It uses the YouTube Data API only for this purpose, with access granted by the channel owner.

Data we access

The app accesses only the channel owner's own Google account authorization (an OAuth token) needed to upload videos. It does not read, collect, or store personal data of any other users or viewers.

Data storage and sharing

The OAuth token is stored as an encrypted secret in a private GitHub Actions configuration and is used only by the upload workflow. We do not sell, share, or transfer any Google user data to third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
